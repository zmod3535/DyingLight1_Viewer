Данная программа на стадии начальной разработки, с возможностью обновления других коддеров, программистов, чтобы её довести до ума, это пока что просто набросок версии интерфейса.
Код можете использовать для своих целей и изучения.
Версия 1.0 не может пока что все меши октрывать.
Поскольку код не может определить что у некоторых мешей паддинг(stride) вершин это typr: 20, если просматривать меши через **Model Research pro**.
У других же моделей статичных паддинг вершин в основном type: 14.
Я решил написать свою версию данного софта для именно первой части DyingLight, поскольку не нашел рабочий вариант для неё, только для части DyingLight 2, но она не корректно работает с первой частью.
Так что, пользуйтесь наздоровье кодом. =)
